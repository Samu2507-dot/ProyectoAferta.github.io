Proyecto Aferta
Descripción

Proyecto Aferta es una página web desarrollada con HTML y CSS enfocada en presentar de forma visual y profesional distintos servicios relacionados con impresión, diseño gráfico y merchandising. El objetivo principal del proyecto es ofrecer una experiencia clara, moderna y accesible para los usuarios, manteniendo una estructura sencilla pero bien organizada.

Este proyecto fue creado por Samuel Callejas Pinto y funciona como una demostración práctica de maquetación web, organización de contenido y diseño visual aplicado a una web corporativa.

Características principales
Diseño web estático y responsive.
Estructura clara y fácil de navegar.
Uso de imágenes y recursos visuales personalizados.
Secciones legales incluidas:
Política de privacidad.
Política de cookies.
Aviso legal.
Estilo visual unificado mediante CSS.
Organización simple del proyecto para facilitar futuras mejoras.
Tecnologías utilizadas

El proyecto fue desarrollado utilizando tecnologías base del desarrollo web frontend:

HTML5 → estructura y contenido.
CSS3 → estilos y diseño visual.

Sin frameworks, sin dependencias innecesarias y sin complicaciones raras. A veces lo simple también funciona muy bien.

Cómo ejecutar el proyecto

Al tratarse de una página web estática, no es necesario instalar dependencias ni configurar servidores.
Sin embargo, si queremos hacerlo más público, si deberemos adquirir un dominio y un servidor para publicarlo.

Opción rápida
Descarga o clona el repositorio.
Abre el archivo index.html en tu navegador.
Clonar el proyecto
git clone <URL_DEL_REPOSITORIO>
Objetivo del diseño

El enfoque del proyecto busca transmitir:

Profesionalidad.
Claridad visual.
Buena organización del contenido.
Facilidad de navegación.

Además, se intenta mantener un equilibrio entre estética y funcionalidad para que la experiencia del usuario sea agradable sin sobrecargar la interfaz.

Recursos visuales

El proyecto incluye diferentes imágenes relacionadas con:

Diseño gráfico.
Impresión digital.
Merchandising.
Gran formato.
Branding corporativo.

Todos estos elementos ayudan a reforzar la identidad visual de la página.

Posibles mejoras futuras

Aunque el proyecto ya cumple correctamente su función, siempre hay margen para seguir mejorándolo:

Añadir JavaScript para interactividad.
Incorporar formularios funcionales.
Optimizar imágenes y rendimiento.
Implementar animaciones suaves.
Adaptar la web a un entorno backend o CMS.
